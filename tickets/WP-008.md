# WP-008: Root CMake — drop the MSVC-only gates

- **Status:** done (commit 7a4d5a8)
- **Phase:** 3 — CMake cross-platformization
- **Priority:** P0 (the `if(NOT MSVC) FATAL_ERROR` is the primary gate)
- **Difficulty:** easy
- **Depends on:** —
- **Plan ref:** PLAN.md §Phase 3, item 1
- **GitHub issue:** #8

## Context

`CMakeLists.txt` line 5–6 rejects every non-MSVC compiler with
`FATAL_ERROR "Willpower currently supports Windows builds with Microsoft Visual C++ only."`.
It also carries an MSVC-only MemCheck/ASan configuration (ASan runtime DLL staging,
`/RTC1` surgery) and global `UNICODE _UNICODE` defines.

## Changes

- [x] Drop the `if(NOT MSVC) FATAL_ERROR`; accept MSVC, GNU, and Clang. Keep the 64-bit check (line ~10).
- [x] Wrap the entire MemCheck/ASan-DLL block in `if(MSVC AND CMAKE_CONFIGURATION_TYPES)`.
- [x] Scope the `UNICODE _UNICODE` defines to `WIN32` (harmless off-Windows, but tidy).

## Files

- `CMakeLists.txt`

## Acceptance criteria

- `cmake -S . -B build` succeeds on Ubuntu with GCC and with Clang.
- Windows multi-config build unchanged: MemCheck configuration still exists with the ASan DLL staging and `/RTC1` handling.
