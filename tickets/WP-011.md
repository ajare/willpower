# WP-011: Application module CMake — compiler-aware warning flags

- **Status:** open
- **Phase:** 3 — CMake cross-platformization
- **Priority:** P1
- **Difficulty:** easy
- **Depends on:** WP-009 (reuse the same compiler-aware pattern)
- **Plan ref:** PLAN.md §Phase 3, item 4
- **GitHub issue:** #11

## Context

`willpower.application/CMakeLists.txt` passes MSVC-only `/W4`. (The Common module's
equivalent change is tracked in WP-004.)

## Changes

- [ ] Make warning flags compiler-aware in the Application module CMake: `/W4` on MSVC,
      `-Wall -Wextra` on GNU/Clang.
- [ ] Fix (or selectively suppress, without changing behaviour) any new warnings
      surfaced in Application sources by `-Wall -Wextra`.

## Files

- `willpower.application/CMakeLists.txt`
- Any Application source files with new GCC/Clang warnings

## Acceptance criteria

- No MSVC-only warning flags are passed when building with GCC/Clang.
- Module builds warning-clean (or with documented suppressions) on both platforms.
