# WP-044: Resource Manifest Editor — author Program, Material, and specialized Definitions

- **Status:** done
- **Phase:** Resource Manifest Editor advanced authoring
- **Priority:** P1
- **Difficulty:** hard
- **Blocked by:** WP-043
- **GitHub issue:** [#44](https://github.com/ajare/willpower/issues/44)

## Context

The editor could author ImageSet and AnimationSet composites, but Program and Material
Resources still lacked constrained drafts and nested forms. Definition creation also had
no catalogue boundary, so a factory could not be selected safely or kept unique.

## Changes

- [x] Add Program drafts with required Vertex and Fragment Shader selectors and a valid
      starter mesh, then expose attributes, mesh settings, buffers, channels, enums,
      booleans, and numeric constraints.
- [x] Add Material drafts with a required Program selector, explicit Image dependency
      creation, texture collections, and atomic resource/default texture alternatives.
- [x] Derive available Definition factories from exact Resource Schema Catalog keys,
      instantiate the selected schema, and reject unregistered or duplicate factories.
- [x] Keep required default Definition deletion invalid while allowing specialized
      Definition deletion when whole-manifest validation succeeds.
- [x] Extend schema-shaped nested controls for constrained scalar selectors, booleans,
      numeric ranges, collections, and alternatives without guessing unsupported data.
- [x] Add a headless advanced-authoring suite covering valid and invalid Programs and
      Materials, default and specialized Definitions, alternatives, canonical output,
      uniqueness, and undo/redo.

## Out of scope

Loading application Resource Schema Bundles into the desktop deployment, schema reload,
custom Resource Type authoring, and semantic save gating remain follow-up work.
