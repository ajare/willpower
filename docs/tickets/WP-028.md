# WP-028: Application — schemas for ImageSet and AnimationSet Resources

- **Status:** open
- **Phase:** Resource Manifest validation — built-in schemas
- **Priority:** P1
- **Difficulty:** hard
- **Blocked by:** [WP-025 / #25](https://github.com/ajare/willpower/issues/25), [WP-026 / #26](https://github.com/ajare/willpower/issues/26)
- **Spec:** `docs/specifications/resource-manifest-schema-validation.md` §§8.6–8.7
- **GitHub issue:** [#28](https://github.com/ajare/willpower/issues/28)

## Context

`ImageSet` and `AnimationSet` have nested default Definitions and required Image dependencies. Their factories currently discover missing fields, malformed values, and invalid enums only when Resources are created, after the Resource Manifest has already been accepted.

## Changes

- [ ] Add the canonical `ImageSet` schema covering `Images/Image`, `Images/ImageSet`, dimensions, coordinates, count, and offsets.
- [ ] Require an ImageSet dependency with ID `Image` and a default Definition containing `Images`.
- [ ] Add the canonical `AnimationSet` schema covering animations, loop styles, frames, frame overrides, offsets, timing, and tags.
- [ ] Model explicit-image and image-set frame modes, including when a frame index is required.
- [ ] Require an AnimationSet dependency with ID `Image` and a default Definition containing `Animations`.
- [ ] Accept native YAML numeric values and strictly parseable quoted numeric strings.
- [ ] Keep loaded-image bounds, referenced image/image-set names, duplicate names, and final materialized-frame timing as semantic checks.
- [ ] Register/embed both schemas and add positive and negative load-time tests for every nested structure and mode.

## Files

- `willpower.application/schemas/image-set.schema.json` (new)
- `willpower.application/schemas/animation-set.schema.json` (new)
- `willpower.application/tests/`

## Acceptance criteria

- Representative valid ImageSet and AnimationSet manifests pass during `scan()`.
- Missing dependencies, required wrappers/fields, invalid loop styles, invalid scalar strings, non-positive dimensions/counts/times, and illegal frame-mode combinations fail during `scan()`.
- Cross-resource and image-bound failures remain reported by semantic/resource creation validation rather than being approximated in JSON Schema.
