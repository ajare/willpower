- **Status:** done (commit 7a5a46b)

## Context

`willpower.common/src/Logger.cpp` (line ~68) calls `localtime_s()`, which is MSVC CRT
and not available in glibc. The file will not compile on Linux.

## Changes

- [x] Use `localtime_r()` on POSIX and `localtime_s()` on MSVC (small `#if` around the call).
- [x] Drop the Windows-only `#if` gate (and trailing `#error`) so the file compiles off-Windows.

- `willpower.common/src/Logger.cpp`
