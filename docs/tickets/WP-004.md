# WP-004: Common — platform-aware CMake (defines, sources, warning flags)

- **Status:** done (commit d2fb353)
- **Phase:** 1 — Willpower.Common (prerequisite)
- **Priority:** P0
- **Difficulty:** medium
- **Depends on:** WP-001 (source gating must match the portable-walker split)
- **Plan ref:** PLAN.md §Phase 1, item 4
- **GitHub issue:** #4

## Context

`willpower.common/CMakeLists.txt` unconditionally defines `WIN32 _WINDOWS _USRDLL`
(line ~42), compiles `src/StackWalker.cpp` (line ~25), and passes MSVC-only `/W4`
(line ~52). None of that works on GCC/Clang.

## Changes

- [x] Define `WIN32 _WINDOWS _USRDLL` only under `if(WIN32)` (generator-expression `$<$<PLATFORM_ID:Windows>:...>`).
- [x] Add `StackWalker.cpp` (and any Windows-only walker sources) to the target only when `WIN32` (already in place from WP-001).
- [x] Make warning flags compiler-aware: `/W4` on MSVC, `-Wall -Wextra` on GNU/Clang.
- [x] Fix (or selectively suppress, without changing behaviour) any new warnings surfaced by `-Wall -Wextra`.

## Files

- `willpower.common/CMakeLists.txt`
- Any Common source files with new GCC/Clang warnings

## Acceptance criteria

- `Willpower.Common` configures and builds on MSVC (multi-config, all configs) and on Linux (GCC + Clang).
- Windows build is byte-compatible in behaviour; no `WIN32`-related defines leak into Linux builds.
