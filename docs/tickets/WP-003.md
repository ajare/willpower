## Context

`willpower.common/include/willpower/common/Exceptions.h` gates `<source_location>` on
`#if _MSC_VER >= 1930`. GCC 11+ also supports `std::source_location`, so the guard should
be the standard feature-test macro rather than a compiler-specific one.

## Changes

- [x] Replace the `_MSC_VER` guard with `#if defined(__cpp_lib_source_location)`.
- [x] Keep the existing `NotImplementedException` fallback path for toolchains without it.

## Files

- `willpower.common/include/willpower/common/Exceptions.h`

## Acceptance criteria

- Compiles with GCC 12+, Clang 15+, and MSVC without changing the generated API on MSVC.
- No `_MSC_VER`-based guards remain in the header.
