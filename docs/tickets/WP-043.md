# WP-043: Resource Manifest Editor — author ImageSet and AnimationSet Definitions

- **Status:** done
- **Phase:** Resource Manifest Editor composite authoring
- **Priority:** P1
- **Difficulty:** hard
- **Blocked by:** WP-042
- **GitHub issue:** [#43](https://github.com/ajare/willpower/issues/43)

## Context

The editor could maintain dependency declarations and file-backed Resources, but
ImageSet and AnimationSet Definitions remained read-only nested YAML. Their compatible
singleton collections, numeric constraints, frame alternatives, and required default
Definitions need transactional controls rather than invalid intermediate documents.

## Changes

- [x] Generate ImageSet and AnimationSet authoring forms from their catalogued schemas,
      including required compatible dependency selectors and valid starter Definitions.
- [x] Render nested image, image-set, animation, explicit-frame, image-set-override, and
      tag properties with numeric constraints, optional values, and loop-style enums.
- [x] Normalize singleton collections to indexed form paths and support add, duplicate,
      remove, and reorder operations with schema validation before commit.
- [x] Support explicit and image-set Frames alternatives while rejecting incomplete
      transitions and required Definition or collection removal atomically.
- [x] Preserve nested diagnostic instance paths for inspector navigation.
- [x] Add headless fixtures for scalar compatibility, both frame alternatives,
      collection boundaries, selectors, canonical output, and undo/redo.

## Out of scope

Program and Material Definition forms, application-provided schema forms, semantic
resource loading, and save-time semantic gating remain follow-up work.
