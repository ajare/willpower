# WP-035: Tools — export and compose Resource Schema Bundles

- **Status:** open
- **Phase:** Resource schema export — tooling
- **Priority:** P1
- **Difficulty:** medium
- **Blocked by:** [WP-032 / #32](https://github.com/ajare/willpower/issues/32), [WP-033 / #33](https://github.com/ajare/willpower/issues/33)
- **GitHub issue:** [#35](https://github.com/ajare/willpower/issues/35)

## Context

Build-generated bundles cover normal downstream projects, but CI scripts and application-specific tooling also need a stable way to inspect, merge, verify, and export catalogs. Applications whose Resource Types are selected or registered in code need a small exporter entry point rather than requiring external tools to load the application itself.

## Changes

- [ ] Add a command-line tool that can list, verify, merge, and export Resource Schema Bundles.
- [ ] Allow the tool to start with Willpower's built-in catalog and accept zero or more downstream bundles.
- [ ] Emit both a complete bundle and a composed root schema suitable for YAML language servers.
- [ ] Provide machine-readable diagnostics and non-zero exit codes for incompatible versions, collisions, hash failures, and unresolved references.
- [ ] Add a small reusable exporter entry point or example target that downstream applications can link with their schema-registration code.
- [ ] Ensure exporting schemas does not require constructing `Resource`, renderer, audio, or platform services.
- [ ] Document reproducible CI and editor-integration examples.

## Acceptance criteria

- The tool exports the nine built-in schemas without loading schema files from the Willpower source tree.
- Supplying a downstream bundle produces a merged bundle and root schema containing its custom Resource Types.
- A downstream example exporter can publish schemas registered by application-owned code without initializing runtime subsystems.
- Invalid or conflicting input fails deterministically and identifies the offending bundle, key, and schema ID.
- Exported output is byte-for-byte stable for identical inputs.
- Automated tests exercise the CLI on Windows and Linux.
